repro — Manual Testing Guide

Validating the proxy against real agents and real API calls. Covers the Phase 1 manual gate, Phase 2 THE GATE, and multi-model testing.

Prerequisites

Before you start
  • Node.js 20+ installed
  • ANTHROPIC_API_KEY set in your shell (a real key, not a dummy)
  • A git repo with at least one commit (the test will use worktrees)
  • Build repro: npm run build
Cost note. Each recording makes live API calls. The reference agent's test prompt uses 2–3 short turns. Budget roughly $0.01–0.05 per recording with Haiku, $0.05–0.20 with Sonnet, more with Opus.

Part 1 — Phase 1 Gate Manual

Goal: a real agent CLI runs to completion through the proxy with no behavioral difference.

1A. Record with the reference agent + real API

Create a throwaway test directory and record:

# Create a test workspace
mkdir -p /tmp/repro-test && cd /tmp/repro-test
git init && git commit --allow-empty -m "init"
echo "the quick brown fox" > test-input.txt
git add -A && git commit -m "add input"

# Record through the proxy — this hits the real Anthropic API
ANTHROPIC_API_KEY=your-key-here \
  node /path/to/repro/dist/cli.js record -- \
  node /path/to/repro/dist/test-fixtures/reference-agent.js \
  "Read test-input.txt and write its content reversed to test-output.txt"
Expected: Agent completes, test-output.txt appears with reversed content. Trace saved under .repro/r-XXXXXX/. No errors.

1B. Inspect the trace

node /path/to/repro/dist/cli.js inspect r-XXXXXX
Expected: Timeline shows process.start → model.request → model.response (with tool calls) → ... → process.exit. No raw API keys visible anywhere.

1C. Verify redaction

# Search for your actual API key in the trace files
grep -r "sk-ant-" .repro/
grep -r "$ANTHROPIC_API_KEY" .repro/
Expected: No matches. Your key was redacted before it hit disk.

Part 2 — THE GATE Critical

Goal: record a real agent run, disconnect the network, replay, and obtain an identical observable event sequence. This is the make-or-break validation.

2A. Record a run (if you haven't already from Part 1)

Use the same recording from Part 1, or record fresh. Note the trace ID.

2B. Verify the trace has a commit

cat .repro/r-XXXXXX/meta.json | grep commit
Expected: A "commit": "abc123..." field present.

2C. Go offline and replay

Network off. Turn off Wi-Fi / disconnect ethernet. The replay must work with no network at all. If it tries to reach the API, it will fail — that's the test. 
# With network disconnected:
node /path/to/repro/dist/cli.js run r-XXXXXX
Expected output:
repro: ✓ reproduced — N events, 0 API calls, 0 API keys
repro: ✓ working tree restored

Exit code 0. The agent ran against recorded responses with zero network access.

2D. Verify worktree cleanup

git status
git worktree list
Expected: Working tree clean. Only the main worktree listed.

2E. Verify strict divergence detection

Modify the input file so the agent will produce different tool results:

# Change the file the agent reads
echo "COMPLETELY DIFFERENT CONTENT" > test-input.txt
git add -A && git commit -m "change input"

# Replay — should detect divergence
node /path/to/repro/dist/cli.js run r-XXXXXX --strict
Expected: repro: ✗ diverged at N point(s) with message index reported. Exit code 1. The agent read different content, sent a different hash, and strict mode caught it.

Reconnect your network before continuing.

Part 3 — Full Loop: Record → Save → Test

3A. Save the recording with assertions

node /path/to/repro/dist/cli.js init
node /path/to/repro/dist/cli.js save r-XXXXXX \
  --title "reverse file contents" \
  --assertion max_calls:10 \
  --assertion forbidden_path:node_modules/**

3B. Run the test suite (offline)

# Disconnect network again
node /path/to/repro/dist/cli.js test
Expected: repro: ✓ 1 passed, ✗ 0 failed, ⚠ 0 diverged. Exit code 0.

Part 4 — Multi-Model Testing

The reference agent hardcodes claude-sonnet-4-20250514. To test other models, set the model via environment or edit the agent. Here's the quick way:

4A. Test with Claude Haiku

# Create a variant agent that uses Haiku
cd /tmp/repro-test
cat > haiku-agent.js <<'AGENT'
import { readFileSync, writeFileSync, mkdirSync } from "node:fs";
import { dirname } from "node:path";

const BASE_URL = process.env.ANTHROPIC_BASE_URL ?? "https://api.anthropic.com";
const API_KEY = process.env.ANTHROPIC_API_KEY ?? "";
const MODEL = process.env.REPRO_MODEL ?? "claude-haiku-4-5-20251001";

const TOOLS = [
  {
    name: "read_file",
    description: "Read a file from the filesystem",
    input_schema: {
      type: "object",
      properties: { path: { type: "string", description: "File path" } },
      required: ["path"],
    },
  },
  {
    name: "write_file",
    description: "Write content to a file",
    input_schema: {
      type: "object",
      properties: {
        path: { type: "string", description: "File path" },
        content: { type: "string", description: "Content" },
      },
      required: ["path", "content"],
    },
  },
];

function executeTool(name, input) {
  try {
    if (name === "read_file") return { result: readFileSync(input.path, "utf-8"), is_error: false };
    if (name === "write_file") {
      mkdirSync(dirname(input.path), { recursive: true });
      writeFileSync(input.path, input.content, "utf-8");
      return { result: "ok", is_error: false };
    }
    return { result: "Unknown tool: " + name, is_error: true };
  } catch (err) { return { result: err.message, is_error: true }; }
}

async function run() {
  const prompt = process.argv[2] ?? "Read test-input.txt and reverse it to test-output.txt";
  const messages = [{ role: "user", content: prompt }];

  for (let turn = 0; turn < 10; turn++) {
    const res = await fetch(BASE_URL + "/v1/messages", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "x-api-key": API_KEY,
        "anthropic-version": "2023-06-01",
      },
      body: JSON.stringify({ model: MODEL, max_tokens: 4096, messages, tools: TOOLS }),
    });
    if (!res.ok) throw new Error("API error " + res.status + ": " + await res.text());
    const data = await res.json();

    messages.push({ role: "assistant", content: data.content });

    if (data.stop_reason === "end_turn") break;
    if (data.stop_reason === "tool_use") {
      const results = data.content
        .filter(b => b.type === "tool_use")
        .map(b => ({
          type: "tool_result",
          tool_use_id: b.id,
          ...executeTool(b.name, b.input),
        }));
      messages.push({ role: "user", content: results });
    }
  }
}

run().catch(e => { console.error(e); process.exit(1); });
AGENT

git add -A && git commit -m "add haiku agent"

4D. Diff across models

# Compare how Haiku and Sonnet approached the same task
node /path/to/repro/dist/cli.js diff r-HAIKU_ID r-SONNET_ID

Expected: Different models produce different traces. The diff shows where they diverge — typically different tool call ordering or arguments. This is normal cross-model behavior, not a bug.

Part 5 — Testing with Claude Code Advanced

The ultimate validation: wrap a real Claude Code session.

Heads up. Claude Code sessions can be long and expensive. Start with a trivial prompt. Also, Claude Code checks for API keys at startup — the proxy already handles this by preserving your real key while intercepting traffic. 
# Set up a simple task
cd /tmp/repro-test
echo "function add(a, b) { return a + b; }" > math.js
git add -A && git commit -m "add math.js"

# Record a Claude Code session with a trivial prompt
# (adjust the path to your repro dist)
node /path/to/repro/dist/cli.js record -- \
  claude --print "Read math.js and add a multiply function to it"
If Claude Code hangs or errors: Some agents validate the API endpoint or check for specific response headers the proxy doesn't set. If this happens, note the error — it's useful feedback for improving proxy fidelity.

If it succeeds, replay offline and run the full gate test from Part 2.

Part 6 — Streaming Validation

The reference agent supports streaming via REPRO_AGENT_STREAM=1. Test that SSE reassembly and re-chunking work with real API responses.

# Record with streaming enabled
echo "hello world" > test-input.txt
git add -A && git commit -m "reset"

REPRO_AGENT_STREAM=1 \
  node /path/to/repro/dist/cli.js record -- \
  node /path/to/repro/dist/test-fixtures/reference-agent.js \
  "Read test-input.txt and write its content reversed to test-output.txt"

# Replay with streaming
REPRO_AGENT_STREAM=1 \
  node /path/to/repro/dist/cli.js run r-STREAM_ID
Expected: Same result as non-streaming. Agent completes, trace replays, no SSE parsing errors.

Troubleshooting

Agent fails with "API error 502"

The proxy couldn't reach the upstream. Check that ANTHROPIC_API_KEY is set and valid, and that you have internet (unless you're deliberately testing offline replay).

Replay fails with "hash not found"

The agent sent a different request than what was recorded. This is expected when the environment changed (different file contents, different git state). Use --lenient to see what happens, or re-record.

Worktree creation fails

The repo needs at least one commit. Also check that the commit hash in meta.json still exists in your repo (hasn't been garbage-collected or rebased away).

"Cannot find module" errors

Make sure you've run npm run build before testing. The CLI runs from dist/, not src/.
